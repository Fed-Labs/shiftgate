# SHIFTGATE continuity film

Deterministic source scene for the 30-second landing film. Render from the web
repo with `python3 scripts/motion/render.py`. The source uses only procedural
SVG geometry and local system tools; it contains no generated imagery, network
assets, or audio. The current render is 1920×1080, 900 frames at 30 fps, H.264
MP4, VP9 WebM, and a WebP poster.
