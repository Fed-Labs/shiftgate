## Ground rules

- This is Next.js 16 with breaking convention changes. Before touching routing,
  metadata, fonts, error boundaries, or the proxy, read the matching guide in
  `node_modules/next/dist/docs/` (start at `index.md`). Notable: error
  boundaries receive `retry` (not `reset`), and per-request middleware lives in
  `src/proxy.ts` exporting `proxy` (not `middleware.ts`).
- The canonical OpenAPI spec is `api/openapi/shift.yaml` at the repo root.
  `public/api/openapi.yaml` is generated — never hand-edit it; run
  `npm run sync-openapi`. `src/lib/types.ts` is hand-maintained but must stay
  contract-true to the spec: `scripts/check-types-drift.mjs` gates drift and is
  run by `sync-openapi` and `validate-content`.
- Content promises are gated. `npm run test:content` fails on: CLI commands or
  global flags not implemented in `cmd/shift/main.go`, unqualified claims like
  "nothing restarted" / "all systems operational", stale API field names
  (`target_machine`, `verify_after_restore`, `/api/v1`), missing/expired
  `public/.well-known/security.txt`, and sitemap ↔ route drift. Add new pages
  to `src/app/sitemap.ts` in the same change.
- Metadata: every public route should carry a title/description (via
  `export const metadata` in a server `layout.tsx` or `page.tsx`; client page
  roots cannot export metadata). `NEXT_PUBLIC_SITE_URL` feeds metadataBase,
  robots, and sitemap.
- Error/loading: route segments get branded `error.tsx` / `loading.tsx`
  boundaries; keep new segment trees inside that pattern. `global-error.tsx`
  must define its own `<html>`/`<body>` and inline styles (globals.css is not
  loaded there).
- Env handling: never bake a developer API origin into production bundles —
  `next.config.ts` fails the production build without `NEXT_PUBLIC_API_URL`,
  and `.env.production` supplies the default.
- Scope discipline: dashboard page components are edited by other workstreams;
  scaffold files (`package.json`, `next.config.ts`, `scripts/*`, `src/proxy.ts`,
  root `layout.tsx`, error/loading boundaries, `public/`) are shared — keep
  changes minimal and table-stakes.
